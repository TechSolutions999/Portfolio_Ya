Public Library

“Cluster, Grid, and Path”

Sport City, Amman — Jordan · Supervised by Dr. Lamees Shaaban

Concept

Cubism as a public civic form

The main element used in the design is a grid to help the clustering stay functional. Clustered architecture is beautiful yet challenging, which is why the Cubism school inspired the design.

The building mingles with its surroundings through material. One of the hardest and most essential ambitions was to create and maintain a pathway through such a clustered building.

A public library must remain functional. Gradation was added so the concept could live without losing civic clarity.
